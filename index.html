Legatus Streamer

Bir yayın kaynağını (NDI, SDI, SRT, dosya) tek tuşla birden çok YouTube ve Facebook hedefine canlı yayınlayan Windows masaüstü programı. Hesap bağlanan hedeflerde yayın başlığı ve açıklaması program üzerinden yazılır.

A Windows desktop application that streams one source (NDI, SDI, SRT, file) to several YouTube and Facebook destinations with one button. For connected accounts, the stream title and description are set from the application.
