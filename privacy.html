Legatus Streamer — Privacy Policy

Last updated: 21 November 2026

Legatus Streamer is a Windows desktop application. It runs entirely on the user's own computer. The developer does not operate any server that receives, stores or processes user data.

What the application accesses

  • YouTube (Google): when the user connects a YouTube account, the application uses the YouTube Data API to read the channel name, create a live broadcast with the title, description and privacy setting the user entered, bind it to a live stream, and end that broadcast when the user stops streaming.
  • Facebook (Meta): when the user connects a Facebook account, the application lists the Pages the user manages, and on the Page the user selects it creates a live video with the title and description the user entered, and ends it when the user stops streaming.

How data is stored

Access and refresh tokens, Page tokens and stream keys are stored only on the user's computer, encrypted with Windows Data Protection (DPAPI) so that only the same Windows user on the same computer can read them. They are sent only to Google or Meta, directly, to perform the actions above. Nothing is sent to the developer or to any third party.

Google API Services

Legatus Streamer's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the streaming features described above, is not used for advertising, is not sold, and is not read by humans.

Removing access

Delete a destination in the application to remove its stored tokens. Access can also be revoked at any time at Google account permissions and in Facebook under Settings › Business integrations / Apps and websites.

Contact

Questions about this policy: open an issue at github.com/legatusonair/legatusonair.github.io, or use the developer contact shown on the Google consent screen.

Gizlilik Politikası (Türkçe)

Erişim anahtarları ve yayın anahtarları yalnız kullanıcının bilgisayarında, Windows DPAPI ile şifreli saklanır; yalnız doğrudan Google'a veya Meta'ya gönderilir, geliştiriciye veya üçüncü kişilere gönderilmez. Google API'lerinden alınan verilerin kullanımı Google API Services User Data Policy'ye (Limited Use dahil) uygundur. İzinler programda hedef silinerek, ayrıca Google hesap izinleri ve Facebook ayarları üzerinden her an kaldırılabilir.
